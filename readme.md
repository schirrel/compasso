# Compasso

This is a study development to learn multiple backend and frontend languages and frameworks.
Supposed to cover a full platform with full features and work cases, such: Identity, Catalog, Partners, Bookings, Payments, Promotions, Search, Reviews, Notifications and Real-time.

### Backend
The is intent to be build with a fully microservices backend using: PHP, Laravel, .NET, Phyton, Django, FastApi, Java Spring, NodeJS and Nest.js.

The backend should include: pub/sub, queue, RestAPI, websocket
### Frontend
In the frontend it will levarage some microfrontend approach, or a multirouting strategy to cover the main frameworks: Angular, React, Vue, Nuxt, Nest, Svelte, Meteor and also a shared library between all.

### Infra
Is desired to use different types of database such: PostgreSQL, MySQL, Redis, Cassandra and MongoDB.
Would run with docker, cdn, ci/cd, blobstorage and more.



## Description
Compasso is a platform for booking in-person classes and experiences (such as yoga, dance, functional training, cooking, pottery, and the like). On one side are individuals looking for classes nearby; on the other are studios and instructors who need to fill their sessions. The model is inspired by existing products designed for class scheduling and marketplaces.
What makes this problem interesting to study is that spots are limited and in high demand, payment must be processed alongside the booking, information is constantly changing (availability, schedules, cancellations), and a diverse range of users interact with the same system, each with their own distinct objectives.
